# EZ Audit — Spec-Driven Development

This directory is the **source of truth** for the EZ Audit conversion: replacing the
Laravel/Next.js stack with the modern SDEE3 stack (React + Vite + TypeScript + Convex +
AWS) while reproducing the *exact* UI the product owner cherishes.

## Workflow

1. **Read** the relevant spec before starting work.
2. **Check status** in each spec header (`implemented` | `partial` | `planned` | `catalog`).
3. **Implement** against the acceptance criteria.
4. **Update** the spec status and link PRs when done.

A `catalog` spec is a gap analysis, not agreed work.

## Locked decisions

| Area | Decision | Rationale |
|------|----------|-----------|
| **UI source of truth** | git `702d652` — *"Fix attempt for the image loading (#1)"*, 2022-06-28 | Last revision containing the full Chakra UI. Screenshots archived in `ezaudit-revive-702/screenshots/`. Cypress from that revision is not ported. |
| **React** | **18.3.x, pinned** | Chakra UI v2 + Emotion need React 18. Pinning is what guarantees the exact UI; do **not** upgrade to 19 as part of this conversion. |
| **UI library** | Chakra UI **v2** + Emotion + `react-icons` | The cherished UI. No Chakra v3 rewrite. |
| **Build** | Vite (current major) + TypeScript (strict) | Matches `../astro-mate` and `../identity`. |
| **Backend** | Convex | Replaces Laravel/PHP + MySQL + Redis + queue + Pusher. |
| **Auth** | SDEE3 Identity hub (`identity.sdee3.com`), Clerk under the hood | Replaces Firebase Auth/Laravel Sanctum/JWT. |
| **Hosting** | AWS S3 + CloudFront, provisioned by `../infrastructure` Terraform | Same estate as the sibling apps. |
| **Packages** | pnpm workspace, Node >= 20 | Matches the sibling repos. |
| **Frontend/backend isolation** | `frontend/` and `backend/` only touch through generated Convex artifacts | Enforced by tsconfig path maps (see spec 01). |

## Repository layout (target)

```
ezaudit/
├── frontend/                 # React 18 + Vite + TS + Chakra v2  (the exact UI)
│   ├── src/
│   ├── public/
│   ├── .env.local            # dev (gitignored)
│   └── .env.production       # generated by scripts/deploy-frontend.sh
├── backend/                  # Convex functions, schema, auth config
│   └── convex/
├── scripts/
│   ├── .env                  # deploy config: BUCKET, DISTRIBUTION_ID, REGION, DIST_DIR
│   └── deploy-frontend.sh    # build + S3 sync + CloudFront invalidate
├── docs/specs/               # this directory
├── package.json              # pnpm workspace root; dev/build/deploy/convex:* scripts
└── pnpm-workspace.yaml
```
